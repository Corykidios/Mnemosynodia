# THE THREE LAWS

### A*1A · THE SPACING IS ICONIC

**The term touching the mark owns the relation.**

```
x.y     both touch   →  fused, intrinsic
x. y    x touches    →  x owns it; the relation runs OUTWARD
x .y    y touches    →  y owns it; the relation runs INWARD
x . y   neither      →  no owner; mutual, parallel, symmetric
```

The whitespace is not an index into a lookup table. **It is a picture of where the relation attaches.**

### A*1B · POSITION DECIDES KIND

**A mark at the head of a name declares a TYPE. A mark between two terms declares a RELATION.**

```
, Orpheus       →  a topic
x,y             →  and
```

**The type is the relation, reified.** There are exactly fifteen marks because there are exactly fifteen free types. No collision is possible, by construction.

### A*1C · THREE MARKS COMPUTE, TWELVE MARKS STATE

```
3 marks × 4 spacings  =  12 operators   —  return a term
12 marks × 4 spacings =  48 connectors  —  return a truth
```

## The Six Modifiers — prefix

| | | |
|---|---|---|
| `\|x` | **not** | ¬ |
| `&x` | **for all** | ∀ — *the ampersand is* et; *∀ is conjunction* |
| `@x` | **there exists** | ∃ — *the eye that finds one* |
| `$x` | **exactly one** | ∃! |
| `/x y` | **lexical** until y | mode switch, bounded |
| `\x y` | **logical** until y | mode switch, bounded |

**Negation is not inversion.** `x\|.y` is *x does not have part y*; `x .y` is *x is part of y*. Two independent bits, four states.
**Quantifier duality holds:** `\|&x` ≡ `@\|x`.

## The Six Associators — enclosing

| | | logical | lexical |
|---|---|---|---|

| `[ ]` | **Signification** | index, specification, range | pronunciation, translation, gloss |

**`[ ]` holds other signs for the same signified. It is the annotator's register** — inside the bracket, the voice changes from the text to the one describing it.
