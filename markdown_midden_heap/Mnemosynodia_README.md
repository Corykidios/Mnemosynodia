# Obsidian Documentation

## Overview
Obsidian is a powerful, local-first knowledge base that works on top of a local folder of plain text Markdown files. It is designed for long-term thinking, personal knowledge management (PKM), and digital gardening.

## Key Features
- **Local-first & Plain-text:** Notes are stored as Markdown files on your device, ensuring data ownership and offline access.
- **Linking & Backlinks:** Use `[[Wikilinks]]` to connect notes. Automatically tracks backlinks to see connections.
- **Graph View:** An interactive visual map of your entire vault, showing how notes and ideas are interconnected.
- **Canvas:** A spatial tool for laying out notes, images, and videos on an infinite board.
- **Extensibility:** 
  - **Core Plugins:** Built-in features like Templates, Daily Notes, and Outliner.
  - **Community Plugins:** 1,000+ plugins like `Dataview` (queries), `Excalidraw` (diagrams), and `Mermaid` (flowcharts).
- **Customization:** Fully customizable interface via themes and CSS snippets.

## Developer Documentation (Plugins & API)
Obsidian provides a robust API for building custom plugins using TypeScript/JavaScript.

### 1. Plugin Lifecycle
A plugin must extend the `Plugin` class and implement the following:
- `onload()`: Called when the plugin is enabled. Use this to register commands, events, and settings.
- `onunload()`: Called when the plugin is disabled. Use this to clean up resources (e.g., event listeners).

### 2. Core API Classes
- **App:** The top-level object providing access to the vault, workspace, and metadata cache.
- **Vault:** Provides a file system abstraction for reading, writing, and managing files and folders within the vault.
- **Workspace:** Manages the UI, including leaf management (panes), ribbons, and statuses.
- **MetadataCache:** Efficiently tracks tags, links, and frontmatter across all notes.

### 3. Key Concepts
- **Commands:** Register functions that users can trigger via the Command Palette (`Ctrl/Cmd + P`).
- **Settings:** Use `PluginSettingTab` to provide a configuration UI in the Obsidian settings menu.
- **Ribbon Icons:** Add buttons to the left sidebar for quick access.
- **Status Bar:** Add information or controls to the bottom right of the UI.
